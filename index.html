The Rescue Loop Problem:

When Lydia drops below 70 mg/dL, you administer 5g rescue carbs. Because Loop's correction target is set to 100–115, Loop sees the rapid post-juice rise and fires an average of 2.31 U of automatic correction boluses.

In Lydia (ISF 210), this extra insulin creates a secondary crash within 90–120 minutes in 71% of rescue episodes.

The Clinical Solution:

Create a custom Temporary Override in Loop named "Hypo Recovery":

  • Target Range: 130 – 140 mg/dL
  • Duration: 45 to 60 minutes
  • Insulin Needs: 100% (or 80%)

Enable this preset whenever administering rescue juice. It raises Loop's correction floor, preventing any auto-bolus from firing during recovery.
